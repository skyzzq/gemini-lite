## 简介（Summary，≤132 字符）*

```
让 Gemini 网页版的长报告不再卡死主线程：面板延迟进布局树 + 正文分块渲染 + 五档字号与浮层切换。
```

（约 47 个字符，留出了后续微调空间。）

## 详细描述

```
Gemini 的 Deep Research 报告面板会一次性把几万个节点和上百个 MathML 公式塞进页面。打开这种会话时，渲染进程的主线程会长期跑满一个核，页面滚不动、点不动，连刷新都会卡住。

Gemini Lite 只做一件事：让这份报告不再把主线程占死。它不改 Gemini 的功能，不读取对话内容，也不向任何服务器发送数据。

【做了什么】
· 延迟放出：面板先在 display:none 下静默建完 DOM，节点数连续稳定后才进入布局树，避免"边建边排"
· 分块渲染：给报告正文的直接子块加 content-visibility，屏幕外的块不参与布局
· 滚动保持：打开或切换面板时记下对话滚到哪，布局稳定后还原，不会被自动顶到最底部
· 打印保底：@media print 下恢复完整渲染，Ctrl+P 存 PDF 不缺内容
· 五档字号：11/12/14/16/18 px，公式跟随正文大小（KaTeX 默认会把公式放大一号）
· 浮层切换：面板可以在 Gemini 自己的右侧栏和整屏浮层之间一键切换；收起时对话自动恢复满宽

【实测数据】
在同一台机器、同一个账号的同一份报告上（面板内 25,045 个节点、377 个公式、整页 74,252 个节点）：
· 强制一次全文档布局：1054.6 ms → 97.2 ms（滚动一遍后再测 30 ms）
· 面板打开期间的 CPU：由单核 102–125% 降到个位数
· 页面内存：不再单向增长

数字来自本地实测，不同报告长度、不同机器会不一样。

【隐私】
· 只申请 storage 权限，用来存你自己选的几个开关
· 不收集、不上传、不出售任何数据
· 没有远程代码，全部逻辑随扩展发布

【已知限制】
· 页面内 Ctrl+F 搜不到还没滚到的段落（离屏块被移出渲染树，这是拿布局成本换可搜索范围的取舍）
· 导出到 Google 文档仍可能卡住，那是网页自己把上万节点转成 Docs 结构，扩展无法介入；建议改用 Ctrl+P 存 PDF

【适用】
Chrome / Edge 111 及以上，仅在 gemini.google.com 与 aistudio.google.com 生效。

Gemini Lite 是独立项目，与 Google LLC 无隶属、未获其背书或赞助。Gemini 是 Google LLC 的商标。
```

## 单一用途说明（Privacy practices 页）

```
Gemini Lite 只有一个用途：降低 Gemini 网页版长报告面板的渲染开销，让页面能正常滚动与输入。它不修改 Gemini 的任何内容或数据，也不与其它站点交互。
```

## 权限理由

`storage`：

```
保存用户自己选择的四个开关（字号档位、是否浮层、是否折叠旧轮次、是否显示调试面板）。不涉及任何个人数据。
```

站点访问 `https://gemini.google.com/*`、`https://aistudio.google.com/*`：

```
扩展的全部功能都在这些页面的 DOM 上生效（给报告面板加延迟释放与分块渲染样式），必须在这两个域上运行。
```
